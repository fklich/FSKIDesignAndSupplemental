This repository exists in support of a basic science document that describes the design of a Full Sky Kinematics and Imaging platform. The .jpeg files are a copy of the document Figures. The .mp4 files are a copy of the animated Figures, including sound tracks. The .ipynb file is the Python code that was used to generate the .mp4 files, and to demonstrate full-sphere celestial separations at 2.5 degrees and 1.25 degrees. The principle Adobe document and it's constituent parts exist in this repository as a simple list including FullSky-SphereKinematicsAndImagingV3.pdf, the *.mp4 animation videos and the *.jpeg images for the document figures.
These files should be zipped up, copied down into a local directory and unzipped. Then, using Adobe to open the FullSky-SphereKinematicsAndImagingV3.pdf should facilitate a complete local review of the document. Several other .jpeg files exist in the repository as actual photographs of 3D printed prototypes with filenames starting with PhotoOf% .
The overriding objective of these documents is to prescribe a platform to facilitate Full Sky Kinematics and Imaging; a means to collect image data for the entire celestial sky, leveraging locations on opposite sides of the sun. In our pursuit of Exoplanets and many other categories of cosmological objects, this capability must evolve to a reality.  In the search for other intelligent life, we can logically assume that these entities would be equipped with such an instrument as FSKI.
